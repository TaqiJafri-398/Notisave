# Changelog

## 1.2.0

- Added a quick pause for notification capture and an option to hide notification previews in the history list.
- Expanded WhatsApp status folder setup guidance and added recovery instructions when folder access is revoked.
- Added an unread-only notification history filter.
- Added a confirmation before permanently pruning older notification history.
- Improved screen-reader labels for search and status-folder setup controls.
- Added password-encrypted notification history backup and merge-on-restore.
- Added device-credential/biometric app lock.
- Added today, last 7 days, and last 30 days history filters.

## 1.1.1

- Replaced broad storage access with Android's system folder picker for WhatsApp statuses.
- Added launcher icons.
