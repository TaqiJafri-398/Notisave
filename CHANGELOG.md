# Changelog

## 1.3.0

- Redesigned all five tabs and the notification detail screen in a flat, monochrome Nothing OS style with 1dp outlines, pill controls, dot-matrix headings (`DotGothic16`), and `#D71921` red reserved for live/active indicators and new markers.
- Added full Light and inverted Dark monochrome themes with zero elevation shadows.
- Automatically hide the Notification Access and WhatsApp Statuses setup cards on Home once permissions are granted, and hide the access-settings button in Settings when enabled.
- Replaced Theme and Retention radio groups with pill segmented controls, and updated switches, checkboxes, search bars, filter chips, and bottom navigation to match the monochrome outline style.
- Read the app version dynamically from package metadata in Settings.

## 1.2.0

- Added a quick pause for notification capture and an option to hide notification previews in the history list.
- Expanded WhatsApp status folder setup guidance and added recovery instructions when folder access is revoked.
- Added an unread-only notification history filter.
- Added a confirmation before permanently pruning older notification history.
- Improved screen-reader labels for search and status-folder setup controls.
- Added password-encrypted notification history backup and merge-on-restore.
- Added device-credential/biometric app lock.
- Added today, last 7 days, and last 30 days history filters.

## 1.1.1

- Replaced broad storage access with Android's system folder picker for WhatsApp statuses.
- Added launcher icons.
